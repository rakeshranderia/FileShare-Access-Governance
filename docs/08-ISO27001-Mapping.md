# ISO 27001 / IAM Alignment

This project is designed as practical supporting evidence for an organisation's access-governance processes within the Windows file-share scope.

Potentially relevant ISO/IEC 27001:2022 Annex A themes include identity management, access rights, information access restriction, privileged access management where applicable, logging/evidence and information ownership/accountability. Exact applicability and control interpretation must be determined within the organisation's ISMS, Statement of Applicability, risk treatment and legal/regulatory context.

The toolkit should therefore be described as **supporting implementation and evidence**, not as providing ISO 27001 compliance by itself.
