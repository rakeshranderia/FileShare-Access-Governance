# Security

This project is a governance reference implementation and does not require secrets in source control.

Do not commit production server inventories, generated access registers, review evidence, credentials, tokens or environment-specific notification configuration.

## Reporting a vulnerability

Please report suspected security vulnerabilities using GitHub Private Vulnerability Reporting for this repository.

Do not open a public issue for suspected vulnerabilities or include production data, credentials, server inventories, access-control evidence or exploit details in a public discussion.

When reporting, include enough information to understand and reproduce the issue where possible, without exposing sensitive or production data.

## Scope

Security reports relating to the published PowerShell code, configuration examples, workflow files or repository automation are welcome.

Operational issues caused by local Active Directory configuration, NTFS permissions, environment-specific credentials or unsupported deployment patterns may fall outside the scope of this repository.
